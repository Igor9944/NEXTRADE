# NexTrade Mobile

Mobile application built with Flutter and Dart.

## Getting Started

This project is a starting point for a Flutter application.

To run the application, you need to have Flutter installed. See the installation guide: https://flutter.dev/docs/get-started/install

Once Flutter is installed, you can run the app with:

```bash
flutter run
```

## Project Structure

- `lib/`: Contains the Dart source code for the application.
  - `main.dart`: Entry point of the application.
  - `core/`: Core utilities and widgets.
  - `features/`: Feature modules.
  - `services/`: Service classes (API, etc.).
  - `models/`: Data models.
- `test/`: Unit and widget tests.

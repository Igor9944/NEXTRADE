# i18n NexTrade

## Langues

`fr` (LTR), `en` (LTR), `ar` (RTL via `document.documentElement.dir`).

## Indépendance

- `nextrade_ui_lang` : langue plateforme
- `nextrade_ai_lang` : langue assistant

Colonnes PostgreSQL `users.ui_language` et `users.assistant_language`. PATCH `/api/v1/profile/me`. Conservé après refresh, navigation, login.

## Couverture UI

Login, sidebar, dashboard, documents, paiement, import/export (titre), assistant.

Les pages métier historiques peuvent encore contenir des libellés non extraits : à étendre progressivement. Une page i18n active n’injecte pas les trois langues dans le même texte de navigation.

Stratégie de tests (FR/EN/AR, RTL, persistance, indépendance IA) : [`docs/test-strategy.md`](test-strategy.md).

## Documents PDF

Factures PDFKit : français (et éventuellement anglais). **L’arabe RTL n’est pas généré dans les PDF** (pdfkit sans reshaper arabe).
